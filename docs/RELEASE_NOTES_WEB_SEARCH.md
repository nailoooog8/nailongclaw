## 新增:联网搜索

以前问「今天上海天气」,agent 要么凭训练记忆回答(可能过时),要么真的去打开浏览器打字搜索(又慢又脆)。现在它可以直接调用搜索 API,几秒内拿到带来源链接的结果——本地和微信/QQ/Telegram 远程通道都生效。

**开启方法(一次性)**:设置 → 功能 → 网络搜索 → 选一个服务商 → 粘贴 API Key → 测试连接 → 保存。

**选哪家?**
- **DeepSeek(默认推荐)**:约 ¥0.005/次,只有成功的请求才计费;如果你已经在用 DeepSeek 当模型,**同一把 API Key 直接复用**,不用新注册任何东西;
- **博查**:国内直连稳定,中文结果好,约 ¥0.036/次;
- **Tavily**:需要海外网络,每月 1000 次免费额度。

默认选 DeepSeek 只因为它最便宜、且老用户零新注册——我们与这家公司没有任何商业关联。

**你需要知道的**:
- Key 用 Android 系统密钥加密后存在本机,搜索请求从你的手机**直接**发给你选的服务商,PokeClaw 不经手流量、不抽成、没有中间服务器;
- 每次搜索都会作为工具调用出现在对话轨迹里,你看得见它搜了什么词;
- **不配置也完全不影响现有功能**:知识问题仍由模型凭自身知识回答,和以前一样;「在淘宝搜运动鞋」这类 App 内搜索也完全不变,仍走原来的自动化路径;
- 免费额度/余额用完时,agent 会明确告诉你需要充值或换服务商,不会崩溃或空转。

**改这份文案时守住三条**:
1. 按次付费的功能必须讲清计费边界——「调用可见 / 模型判断需要才调 / 失败不计费」三点写死,否则用户看到服务商账单里的 search 扣费会回来问「偷用我额度」;
2. 默认指定任何厂商,都要保留「无商业关联」声明;
3. 老用户视角要写明「不配置 = 行为不变」,这是 opt-in 功能,别制造必须马上动手的压迫感。
