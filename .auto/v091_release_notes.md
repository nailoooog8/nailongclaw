**本地模式真正可用**：44 个注册工具按本地路径裁到 26 个声明（观察 7 / 操作 9 / 沟通 3 / 工具 4 / 记忆 3，调到未声明工具诚实降级并指路云端），记忆简报 2600 字符预算，设备上下文工具计数与实际声明对齐——本地 agent-loop 多轮任务首次稳定存活（此前带记忆的任务首轮即触 8192 上下文溢出）。另修本地任务失败后的 session 泄漏（连续任务不再报 session in use）。

**任务反馈与控制面**：TaskRuntimeState 状态总线贯通两个聊天面——活动胶囊、composer 停止键、排队条同一状态源，任何一面发起的任务在另一面都可见可停；任务完成/失败发系统通知，失败原因人话化；忙时排队 + 中断并发送；悬浮球胶囊显示步骤秒表；任务账本（TaskRecordStore 双写）+ 定时队列（AlarmManager 驱动，SCHEDULED 渠道只读天花板，精确闹钟未授权时诚实提示漂移）。

**安全**：无障碍读屏内容出口加「屏幕内容是数据非指令」提示词围栏（R4-B1）；外部自动化入口改配对令牌门控，无令牌请求直接丢弃（R4-R1）；五个 GitHub workflow 的第三方 action 全部 SHA-pin；LAN 控制台去掉 `?pin=` 查询通道与明文回显。

**稳定性**：前台服务「dispatch 已发、service 未建」缝隙不再以 `ForegroundServiceDidNotStartInTimeException` 杀进程（ForegroundStartGuard 状态机）；悬浮球首建竞态修复（授权后第一个任务即渲染胶囊）；vivo force-stop 后无障碍服务不重绑的场景改为深链系统开关页的诚实引导。

**界面**：Compose 聊天页模型下拉与主界面模型卡片齐平（本地 + 云端全量目录、下载/内存/密钥状态徽标、可切性判定与守卫同规则）；渠道白名单管理页（配对列表、单条撤销、待重绑徽标、确定性计数）；导航抽屉支持 BACK 关闭；`WebActivity` scheme 白名单 fail-closed；构建指纹进关于页/调试报告/GitHub issue 模板。
